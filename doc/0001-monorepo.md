# ADR-0001: Monorepo

## Status
Accepted — 2026-10-20

## Context
Небольшая команда, ядро и три клиента разделяют контракты
(Kafka-схемы, client manifest). Раздельные репозитории создают
боль с синхронизацией версий схем и атомарными изменениями.

## Decision
Монорепо с uv workspace. Все сервисы — отдельные Python-пакеты
в одном репозитории.

## Consequences
+ Атомарные коммиты через границы сервисов
+ Единый CI, общие утилиты, единая версия Python
+ Легко менять контракты
- Размер репозитория растёт со временем
- Требуется настройка workspace (uv)
